# 棱镜更新日志

## 0.2.0 · 2026-11-05

- 接通生图配置、Images 与异步任务接口、生成图片和参考图裂变。
- 大于 40 张的请求先审批，批次由 dsh 后台任务观察和取消，生成图片自动进入素材库。
- 增加结果页、会话右侧栏、对话结果卡片和按批次号搜索。
- 文本模型与生图 Key 改用 Windows 凭据管理器，旧文本凭据成功迁移后清除文件中的秘密字段。
- 调整业务服务退出等待时间，并修正 Prism 既有测试的类型声明和客户端测试辅助文件归属。

本版本号用于受影响的 Prism 私有插件，dsh 底座版本保持不变。Windows 安装包仍属于 D5。
